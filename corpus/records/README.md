# Council voting record

Source: Toronto Open Data — Member Voting Record, 2022–2026 council term
(46,815+ vote rows, 2022-11-23 to 2026-08-05), downloaded 2026-10-23.

The single CSV (~12 MB) exceeds the GitHub connector's upload limit, so it is
stored here split into four parts, each with the header row repeated:

- member-voting-record-2022-2026-part1.csv
- member-voting-record-2022-2026-part2.csv
- member-voting-record-2022-2026-part3.csv
- member-voting-record-2022-2026-part4.csv

To recombine into one file: concatenate the parts in order and drop the
repeated header line at the start of parts 2–4.
